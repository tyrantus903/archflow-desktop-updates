# ArchFlow Desktop para Windows

Este repositório distribui instaladores assinados do ArchFlow. O aplicativo consulta o manifesto do seu canal, verifica a assinatura do pacote e pede confirmação antes de instalar.

As releases com a identificação **QA** destinam-se ao ambiente de testes com dados fictícios. Para uso no escritório, utilize o instalador **Piloto** fornecido pelo responsável pelo ArchFlow. Os projetos e documentos permanecem no computador do arquiteto.
